# Веб-приложение «Сервис бронирования жилья»

Данный репозиторий содержит исходный код веб-приложения для автоматизации процессов краткосрочной аренды недвижимости. Проект разрабатывается в рамках дисциплины «Системная и программная инженерия».

## Назначение системы
Цифровизация рутинных процессов бронирования, обеспечение безопасности сделок (защита от овербукинга) и создание интуитивно понятного интерфейса для взаимодействия между арендатором (Гостем) и арендодателем (Хозяином).

## Технологический стек (Трехуровневая архитектура)
* **Уровень представления (Frontend):** React.js, HTML5, CSS3/Tailwind
* **Уровень приложений (Backend):** Node.js / Python (на этапе утверждения)
* **Уровень данных (СУБД):** PostgreSQL

## Стратегия ветвления (Git Flow)
В проекте используется следующая стратегия работы с ветками:
* `main` — стабильная версия приложения (продакшен);
* `develop` — ветка для интеграции новых функций и тестирования;
* `feature/...` — ветки для разработки отдельных модулей (например, `feature/auth`, `feature/booking`).
